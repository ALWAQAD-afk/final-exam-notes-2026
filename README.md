# ملخص الامتحان النهائي 2026

مشروعان في مستودع واحد، منشوران على GitHub Pages:

| الصفحة | الرابط | الطابع |
|---|---|---|
| `index.html` | https://alwaqad-afk.github.io/final-exam-notes-2026/ | بوابة ملفات ساخرة: واجهة واقعية ثم مقلب من أربع مراحل |
| `archive.html` | https://alwaqad-afk.github.io/final-exam-notes-2026/archive.html | أرشيف أكاديمي جدي تمامًا: تتبّع صامت ثم «تقرير الجلسة» |

> **تنبيه للمطوّر:** المحتوى ترفيهي. الجامعة والأرقام والملفات والشخصية خيالية،
> ولا توجد أي ملفات دراسية حقيقية في المستودع.

## الصفحة الأولى — `index.html`

بوابة تحميل بواجهة عربية فصيحة من اليمين إلى اليسار:

1. **واجهة مكتبة واقعية:** إحصائيات مباشرة، مؤقّت، وستة تبويبات (الميد، الفاينل،
   الكويزات، المشروعات، السنوات السابقة، الكل) تضم 20 بطاقة ملف بتواريخ تحديث
   وأعداد صفحات وأسماء ملفات وأزرار تحميل. أي زر يفتح سلسلة التحقق نفسها.
2. **التحقق الأكاديمي:** سؤال ساخر + تعهّد إلزامي.
3. **التحميل المبالغ فيه:** شريط برسائل تقنية يتوقف عند **99%** ثلاث ثوانٍ.
4. **المفاجأة:** تنزيل `final-summary-2026.zip` ثم شاشة صور متساقطة، عدّاد مباشر،
   وزر «إغلاق وإلغاء» يهرب ويضاعف الصور عند الضغط عليه.

## الصفحة الثانية — `archive.html`

تجربة مستقلة بلا أي سخرية أو تنبيهات:

- أرشيف أكاديمي هادئ مع بحث وتصفية حسب النوع والفصل والترتيب، و20 ملفًا
  في خمسة أقسام (الميد، الفاينل، الكويزات، المشروعات، مذكرات المحاضرات).
- تتبّع صامت داخل الجلسة في المتصفح فقط: الثواني، النقرات والتنقلات، الملف
  المختار، والوقت المحلي.
- بعد «تجهيز الملف للتحميل» يمر شريط هادئ ثم تظهر شاشة **«تقرير الجلسة»**
  بأرقام حقيقية من الجلسة.
- زر «حفظ إيصال الجلسة» ينزّل `session-record.txt`، وزر «أغلق الصفحة وابدأ
  الدراسة» يترك شاشة فارغة فيها: «الكتاب أمامك.»

## البنية

```
.
├── index.html                  # الصفحة الساخرة
├── archive.html                # الأرشيف الجدي المستقل
├── assets/
│   ├── style.css               # أنماط الصفحة الأولى
│   ├── app.js                  # منطق المراحل الأربع + تبويبات المكتبة
│   ├── archive.css             # أنماط الأرشيف (ورقية هادئة)
│   ├── archive.js              # التصفية، الاختيار، التتبّع، التقرير، الإيصال
│   ├── favicon.svg
│   ├── favicon-archive.svg
│   └── img/                    # 12 صورة PNG أصلية (512×512)
├── final-summary-2026.zip      # الصور الصالحة نفسها، جاهزة للتنزيل
├── tools/
│   ├── generate_assets.py      # يرسم الصور برمجيًا (بدون مكتبات خارجية)
│   ├── validate_images.py      # فحص صارم: ترويسات، CRC، أبعاد، محتوى فارغ
│   └── build_zip.py            # بناء الأرشيف + التحقق منه (CRC + SHA-256)
├── VERIFICATION.md
├── .nojekyll
└── README.md
```

## التشغيل محليًا

```bash
python3 -m http.server 8080
# الصفحة الأولى: http://localhost:8080
# الأرشيف:       http://localhost:8080/archive.html
```

## إعادة توليد الصور والأرشيف

```bash
python3 tools/generate_assets.py
python3 tools/validate_images.py assets/img --delete --json report.json
python3 tools/build_zip.py
```

## النشر

GitHub Pages من الفرع `main` (المجلد الجذري). كل المسارات نسبية، لذا تعمل
الصفحتان من أي مسار فرعي دون تعديل.

## استبدال الصور

الصور الحالية مرسومة خصيصًا للمشروع لشخصية خيالية. إن رغبت في استخدام صور
أخرى، استبدل ملفات `assets/img/portrait-*.png` بصور تملك حق استخدامها وبموافقة
أصحابها، ثم أعد تشغيل `tools/validate_images.py` و`tools/build_zip.py`.
