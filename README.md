# ملخص الامتحان النهائي 2026 — النسخة السرية

موقع ثابت ساخر (Static) بواجهة عربية من اليمين إلى اليسار، يحاكي بوابة أكاديمية
مبالغ في جدّيتها لتحميل «ملخص الامتحان النهائي»، ثم يكشف المزحة بعد سلسلة
خطوات تحقّق وتحميل متعمّدة التعقيد.

> **تنبيه:** المشروع ترفيهي بالكامل. الجامعة والأرقام والشخصية خيالية.
> لا يحتوي الموقع ولا الملف المضغوط على أي صورة لشخص حقيقي، ولا على أي مادة دراسية.

## ما الذي يحدث؟

1. **البوابة:** إحصائيات وهمية (مرات التحميل، حالة الخادم، حجم الملف) ومؤقّت
   تنازلي يدّعي أن الرابط سيُغلق.
2. **التحقق الأكاديمي:** سؤال ساخر + تعهّد إلزامي بأنك درست المادة.
3. **التحميل المبالغ فيه:** شريط تقدّم برسائل تقنية وهمية يتوقّف عند **99%**
   لمدّة ثلاث ثوانٍ بالضبط.
4. **المفاجأة:** يبدأ تنزيل `final-summary-2026.zip`، ثم تتحوّل الصفحة إلى
   شاشة تتساقط فيها صور «أبو الملخص» مع عدّاد مباشر، وزر «إغلاق وإلغاء»
   يهرب من المؤشّر، ويضاعف عدد الصور عند نجاح الضغط عليه.

## البنية

```
.
├── index.html                  # الواجهة كاملة (RTL)
├── assets/
│   ├── style.css               # التصميم والاستجابة للهواتف
│   ├── app.js                  # منطق المراحل الأربع (بدون مكتبات)
│   ├── favicon.svg
│   └── img/                    # 12 صورة PNG أصلية (512×512)
├── final-summary-2026.zip      # الصور الصالحة نفسها، جاهزة للتنزيل
├── tools/
│   ├── generate_assets.py      # يرسم الصور برمجيًا (بدون مكتبات خارجية)
│   ├── validate_images.py      # فحص صارم: ترويسات، CRC، أبعاد، محتوى فارغ
│   └── build_zip.py            # بناء الأرشيف + التحقق منه (CRC + SHA-256)
├── .nojekyll
└── README.md
```

## التشغيل محليًا

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## إعادة توليد الصور والأرشيف

```bash
python3 tools/generate_assets.py
python3 tools/validate_images.py assets/img --delete --json report.json
python3 tools/build_zip.py
```

`validate_images.py` يرفض صفحات HTML المتخفّية بامتداد صورة، والملفات
الفارغة أو المقتطعة، والصور أحادية اللون، ويتحقق من CRC لكل مقطع PNG.

## النشر

الموقع منشور عبر GitHub Pages من الفرع `main` (المجلد الجذري). كل المسارات
نسبية، لذا يعمل الموقع من أي مسار فرعي دون تعديل.

## استبدال الصور

الصور الحالية مرسومة خصيصًا للمشروع. إن رغبت في استخدام صور أخرى، استبدل
ملفات `assets/img/portrait-*.png` بصور تملك حق استخدامها وبموافقة أصحابها،
ثم أعد تشغيل `tools/validate_images.py` و`tools/build_zip.py`.
