# ملخص الامتحان النهائي 2026 — النسخة السرية

موقعان في مستودع واحد، منشوران على GitHub Pages:

| الصفحة | الرابط |
|---|---|
| `index.html` | https://alwaqad-afk.github.io/final-exam-notes-2026/ |
| `archive.html` | https://alwaqad-afk.github.io/final-exam-notes-2026/archive.html |

`index.html` موقع ساخر بواجهة عربية من اليمين إلى اليسار، يحاكي بوابة أكاديمية
مبالغ في جدّيتها لتحميل «ملخص الامتحان النهائي»، ثم يكشف المزحة بعد سلسلة
خطوات تحقّق وتحميل متعمّدة التعقيد. و`archive.html` صفحة أرشيف أكاديمي جديّة
مستقلة تمامًا، بتجربة منفصلة وتتبّع صامت للجلسة.

> **تنبيه:** المشروع ترفيهي بالكامل. الجامعة والأرقام والشخصية خيالية.
> لا يحتوي الموقع ولا الملف المضغوط على أي صورة لشخص حقيقي، ولا على أي مادة دراسية.

## الموقع الأول — `index.html`

1. **البوابة:** إحصائيات وهمية (مرات التحميل، حالة الخادم، حجم الملف) ومؤقّت
   تنازلي يدّعي أن الرابط سيُغلق.
2. **التحقق الأكاديمي:** سؤال ساخر + تعهّد إلزامي بأنك درست المادة.
3. **التحميل المبالغ فيه:** شريط تقدّم برسائل تقنية وهمية يتوقّف عند **99%**
   لمدّة ثلاث ثوانٍ بالضبط.
4. **المفاجأة:** يبدأ تنزيل `final-summary-2026.zip`، ثم تتحوّل الصفحة إلى
   شاشة تتساقط فيها صور «أبو الملخص» مع عدّاد مباشر، وزر «إغلاق وإلغاء»
   يهرب من المؤشّر، ويضاعف عدد الصور عند نجاح الضغط عليه.

## الموقع الثاني — `archive.html`

أرشيف أكاديمي رقمي هادئ بلا أي سخرية أو تنبيهات:

- بحث عربي وتصفية حسب النوع والفصل والترتيب، و20 ملفًا في خمسة أقسام
  (الميد، الفاينل، الكويزات، المشروعات، مذكرات المحاضرات).
- تتبّع صامت داخل الجلسة في المتصفح فقط: الثواني، النقرات والتنقلات،
  الملف المختار، والوقت المحلي.
- بعد «تجهيز الملف للتحميل» يمر شريط هادئ ثم تظهر شاشة **«تقرير الجلسة»**.
- زر «حفظ إيصال الجلسة» ينزّل `session-record.txt`، وزر «أغلق الصفحة
  وابدأ الدراسة» يترك شاشة فيها: «الكتاب أمامك.»

## البنية

```
.
├── index.html                  # الواجهة الساخرة كاملة (RTL)
├── archive.html                # الأرشيف الجدي المستقل
├── assets/
│   ├── style.css               # تصميم الصفحة الأولى واستجابتها للهواتف
│   ├── app.js                  # منطق المراحل الأربع (بدون مكتبات)
│   ├── archive.css             # تصميم الأرشيف
│   ├── archive.js              # التصفية والاختيار والتتبّع والتقرير
│   ├── favicon.svg
│   ├── favicon-archive.svg
│   └── img/                    # 12 صورة PNG أصلية (512×512)
├── final-summary-2026.zip      # الصور الصالحة نفسها، جاهزة للتنزيل
├── tools/
│   ├── generate_assets.py      # يرسم الصور برمجيًا (بدون مكتبات خارجية)
│   ├── validate_images.py      # فحص صارم: ترويسات، CRC، أبعاد، محتوى فارغ
│   └── build_zip.py            # بناء الأرشيف + التحقق منه (CRC + SHA-256)
├── .nojekyll
└── README.md
```

## التشغيل محليًا

```bash
python3 -m http.server 8080
# الصفحة الأولى: http://localhost:8080
# الأرشيف:       http://localhost:8080/archive.html
```

## إعادة توليد الصور والأرشيف

```bash
python3 tools/generate_assets.py
python3 tools/validate_images.py assets/img --delete --json report.json
python3 tools/build_zip.py
```

`validate_images.py` يرفض صفحات HTML المتخفّية بامتداد صورة، والملفات
الفارغة أو المقتطعة، والصور أحادية اللون، ويتحقق من CRC لكل مقطع PNG.

## النشر

الموقعان منشوران عبر GitHub Pages من الفرع `main` (المجلد الجذري). كل
المسارات نسبية، لذا تعمل الصفحتان من أي مسار فرعي دون تعديل.
